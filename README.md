# Nolan Minh Dinh · Data portfolio

Portfolio song ngữ (Anh / Việt) dành cho Data Analytics, BI và Applied AI. Trang tĩnh, chạy trực tiếp trên GitHub Pages; không cần cài đặt hoặc build.

## Xem tại máy

Mở `index.html` hoặc `index-vi.html` trong trình duyệt. Để kiểm tra đầy đủ tính năng sao chép email, dùng máy chủ HTTP cục bộ.

## Cấu trúc

- `index.html`, `index-vi.html`: nội dung hai ngôn ngữ, sáu hồ sơ dự án, kinh nghiệm và chứng chỉ.
- `portfolio-design.css`: hệ thống màu, chữ, bố cục, responsive và chế độ giảm chuyển động.
- `portfolio.js`: bộ lọc, hộp thoại dự án/chứng chỉ, menu điện thoại và sao chép email.
- `images/design/`: hình minh họa SVG riêng cho portfolio.
- `images/`, `cv/`: tài nguyên gốc được giữ lại.

Chỉnh nội dung tương ứng trong cả hai trang khi cập nhật dự án. Bộ lọc dùng thuộc tính `data-category`; cửa sổ chi tiết liên kết qua `data-dialog` và `id`.

## Định hướng thiết kế

Nền giấy sáng, chữ lớn kết hợp serif nghiêng, tím indigo và đồ họa dữ liệu. Đưa dự án lên trước kinh nghiệm, tách nội dung chuyên sâu vào hộp thoại để trang chính dễ đọc.

Tham khảo cách giới thiệu chuyên môn và tổ chức nội dung từ [Yan Holtz](https://www.yan-holtz.com/), cách kể chuyện bằng hình ảnh dự án từ [Shirley Wu](https://sxywu.com/), và cách trình bày kinh nghiệm từ [Brittany Chiang](https://brittanychiang.com/). Không sao chép mã nguồn hoặc tài nguyên hình ảnh của các trang tham khảo.

Hình vẽ trong `images/design/` là minh họa ý tưởng, không phải ảnh dashboard hoặc dữ liệu đo lường trực tiếp. Bối cảnh và kết quả dự án được giữ từ portfolio gốc; cần cập nhật cùng tài liệu minh chứng khi dự án thay đổi.

## Đưa lên GitHub Pages

Đặt các tệp và thư mục trong repo `nolanminhdinh.github.io`, giữ nguyên đường dẫn tương đối. Không cần thay đổi cấu hình build hoặc thêm dịch vụ hosting. Font được tải từ Google Fonts và có font dự phòng.
