APPLIED AI / AUTOMATION

Build Phase: Data Annotation Operations & Hybrid Power BI Pipeline

Python ETLCVAT REST API v2GitHub GraphQLPower BI (Star Schema)Advanced DAX (20 Measures)GitHub Actions CronTelegram Bot
01 / The question

Fragmented tracking across CVAT & GitHub; 2–4 hours spent manually compiling metrics before weekly mentor reviews, with missed edge cases and no quantitative QA velocity metrics.

02 / The approach

As Project Lead, engineered an end-to-end automated pipeline & Hybrid BI model: Python ETL pulling CVAT REST API v2 & GitHub GraphQL, modeled a 9-table Star Schema with 20 DAX measures across 5 Power BI report pages, automated Jinja2/LLM report drafting, and scheduled GitHub Actions dispatch with Telegram alerts.

03 / The outcome

Saved 2–4 hours per review session through 100% automated aggregation, generated instant CVAT frame deep links for dispute resolution, and established a dual quality evaluation framework (Ground Truth + Reviewer Audit).
